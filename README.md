# Flatana

This tool attempts to flatten all polygons on a mesh.

The changes are made through multiple successive iterations with the vertices that make up the polygon being shifted along the polygon's normal so that the polygon becomes as flat as possible.

Attention
-
After using this tool, the mesh's shape may change.

After using the tool, non-flat polygons may still remain on the mesh.

-
- Download the *.zip archive with the add-on distributive.
- The “Preferences” window — Add-ons — Install from Disk… — specify the downloaded archive.
